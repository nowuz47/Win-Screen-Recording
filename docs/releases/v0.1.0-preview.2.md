## 설치형 EXE와 창 드래그 수정

`Glide-Setup-0.1.0-preview.2-x64.exe`를 내려받아 실행하세요. Windows 11 이상 x64용이며 자체 포함 런타임으로 구성되어 있습니다.

- 관리자 권한 없이 현재 사용자에게 설치합니다. 기본 위치: `%LOCALAPPDATA%\Programs\Glide`
- 시작 메뉴 바로 가기를 등록하며 바탕 화면 바로 가기는 선택할 수 있습니다.
- Windows 설정의 설치된 앱에서 제거할 수 있습니다. 녹화 및 설정 데이터는 보존합니다.
- 업데이트하기 전에 실행 중인 Glide를 종료해 주세요. 설치 프로그램은 녹화 중인 앱을 자동 종료하지 않습니다.
- 설치 없이 사용하려면 `Glide-windows-x64.zip`을 새 폴더에 압축 해제하고 `Glide.App.exe`를 실행하세요.

### 창 이동 수정

메인 창과 녹화·발표 패널을 끌 때 창 위치가 과도하게 이동할 수 있는 좌표 누적 경로를 제거했습니다. Windows 기본 창 이동 처리에 맡기며 방향키 이동은 유지됩니다.

### 검증 범위

Windows 빌드 및 기존 자동 검사와 함께 설치·동일 버전 재설치·제거를 검사합니다. 설치 파일 전체의 해시 일치, 시작 메뉴 바로 가기, 사용자별 제거 등록, 제거 후 사용자 데이터 보존을 확인합니다. 이는 무인 설치 검사이며 대화형 설치 마법사 전체의 실제 UX 검증을 대체하지 않습니다.

Parallels는 실행 중이지만 제어 도구 입력이 전달되지 않아 **수정본의 실제 마우스 드래그 검증은 미완료**입니다. 다중 모니터와 배율 전환도 실측하지 않았습니다.

**서명되지 않은 개발 프리뷰이며 Production Ready 상태가 아닙니다.** 코드 서명이 없어 Windows에서 출처 경고가 나타날 수 있습니다. `SHA256SUMS.txt`로 다운로드 파일을 검증할 수 있습니다.
