## 기본 드래그 영역 적용

`Glide-Setup-0.1.0-preview.3-x64.exe`로 설치하거나 기존 설치를 업데이트하세요. 실행 중인 Glide는 먼저 종료해 주세요.

메인 창 상단 빈 공간과 녹화·발표 제어 패널 손잡이를 Windows 기본 캡션 영역으로 등록하도록 변경했습니다. Preview 2의 XAML PointerPressed → 마우스 상태 조회 → 캡처 해제 → 이동 메시지 전송 절차를 제거했습니다. Windows가 최초 입력부터 창 이동을 처리합니다.

- 창 안에서 좌표를 누적하거나 뒤늦게 커서 위치를 조회하지 않습니다.
- 창 레이아웃과 DPI 변경 시 드래그 영역을 갱신합니다.
- 배율 변환과 버튼 경계에서의 영역 계산을 회귀 검사에 추가했습니다.
- 방향키 이동은 유지합니다.

### 검증 범위

C# 부분 컴파일과 드래그 영역·UI 설정 검사 10개를 통과했습니다. Windows 빌드와 자동 검사, 설치·재설치·제거 결과는 연결된 Actions 실행에서 확인하세요.

**실제 드래그 검증은 아직 미완료입니다.** Parallels에서 PowerShell 창은 확인했지만 도구의 키·클릭 입력이 전달되지 않고 붙여넣기가 시간 초과되어 자동 조작을 진행하지 못했습니다. 사용자 환경의 체감, 다중 모니터 이동 및 배율 전환을 검증 완료로 표시하지 않습니다.

관리자 권한 없이 현재 사용자에게 설치하며 시작 메뉴와 앱 제거를 지원합니다. 녹화와 설정 데이터는 제거 시 보존합니다. ZIP도 제공하며 `SHA256SUMS.txt`로 파일을 검증할 수 있습니다. 서명되지 않은 개발 프리뷰이며 정식 출시 판정이 아닙니다.
