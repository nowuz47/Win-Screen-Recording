# 두 모드 추가 출시 기준

2026-09-12 · 기존 [G00~G11](04-production-readiness.md)의 추가 필수 조건

이 수치는 측정 전에 고정한 제품 목표입니다. 모든 항목은 현재 **PENDING**이며 기존 게이트의 수치·표본·검토 요구를 낮추지 않습니다. 대상 빌드와 측정 환경, 실패 표본을 함께 보존합니다.

2026-09-12의 짧은 Parallels 검사에서는 발표 통합 4/4와 주요 UI 흐름을 확인했지만, 아래 장비·반복 수·접근성·독립 검토 조건을 충족하지 않아 게이트 PASS로 승격하지 않았습니다. [실제 UI 녹화 품질](validation/windows-app-ui-2026-09-12-modes.json)은 최대 466.67ms 프레임 간격과 빈 색상 패치 프레임 때문에 **FAIL**이며 전체 출시 판정은 **NOT READY**입니다.

UI 모션을 추가한 후보에는 [앱 모션의 성능·접근성 조건](08-ui-motion.md#출시-판정)도 적용합니다. 실제 합성기 기능 검사 6/6과 설정 검사 6/6은 통과했지만 M10 및 장비별 성능 게이트는 여전히 **PENDING**입니다.

M04는 회의 앱이나 Windows 캡처 제외 API를 보안 경계로 보증한다는 뜻이 아닙니다. 실제 공유한 출력 창의 내용과 지원 조합을 검증하는 항목입니다. 보안 데스크톱·보호 콘텐츠 등 기존 미지원 범위는 유지합니다.

실제 담당자·독립 검토자·대상 빌드 해시·검증 날짜·환경·결함 목록이 빠진 항목은 PASS로 표시할 수 없습니다. 프레젠테이션 모드 추가 후에도 캡처·오디오·편집·MP4·PNG·공유를 포함한 기존 GA 범위를 그대로 유지합니다.
